# 03 · 安全测试用例（OWASP Top 10 适用性裁剪）

**项目**：文档朗读器 v1.0.0　**分类**：SEC
**适用性声明**：本项目是**单机离线 GUI 应用**，无服务端、无账户体系、无数据库、无网络出站。因此 OWASP Top 10 中「访问控制 / 认证失败 / SSRF」等类目不适用，按 QA 规范以「N/A + 代码级论证」记录，并写成**可执行的静态验证测试**（验证该能力确实不存在），而不是留空。安全覆盖率目标：10 个类目中至少 9 个有明确结论。

| OWASP 类目 | 适用性 | 结论来源 |
|---|---|---|
| A01 访问控制缺陷 | N/A（单机单用户，无 RLS/权限提升面） | TC-SEC-010 |
| A02 加密失败 | 适用（本地凭证/密钥落盘） | TC-SEC-006 |
| A03 注入 | 适用（子进程调用 say / 文本输入） | TC-SEC-001 / 002 |
| A04 不安全设计 | 适用（畸形输入、资源边界） | TC-SEC-004 / 009 |
| A05 安全配置错误 | 适用（动态库注入面、错误信息） | TC-SEC-003 / 005 / 008 |
| A06 自带组件漏洞 | 适用（依赖版本约束） | TC-SEC-007 |
| A07 认证失败 | N/A（无登录/会话/CSRF） | TC-SEC-011 |
| A08 软件与数据完整性失败 | 适用（状态文件、断点 hash） | TC-SEC-006 / TC-CORE-018 |
| A09 日志与告警失败 | 适用（错误可见性） | TC-SEC-005 / TC-GUI-010 |
| A10 SSRF | N/A（无网络出站） | TC-SEC-012 |

### TC-SEC-001: 命令注入 — 恶意文档文本不得进入 shell
**优先级**: P0　**类型**: 安全 / A03　**预估**: 2 min
**前置条件**: 桩捕获 `_run` 的调用参数，缓存目录隔离到 tmp。
**测试步骤**: 1. 构造句子文本 `"; touch /tmp/pwned_QA; rm -rf $HOME; #` 与反引号/`$(...)`/`\n` 变体；2. 调用 `SpeechEngine.synthesize(text)`；3. 检查 `_run` 收到的 argv 与 input_text；4. 确认 `/tmp/pwned_QA` 不存在。
**预期结果**: ✅ `subprocess.run` 使用 **list 参数**且 `shell` 未被设置；✅ 恶意文本只出现在 `input=`（stdin），不出现在任何 argv 元素；✅ 没有文件被创建；✅ `say -f -` 从标准输入读取。
**通过/失败**: 任何字符串拼接进命令、或副作用文件出现，判 P0 失败并立即停止发版。
**潜在缺陷**: 早期版本用 `-f <临时文件>` 且文件名来自文本，存在路径注入风险。

### TC-SEC-002: 路径遍历 — 缓存键不可控文件名
**优先级**: P0　**类型**: 安全 / A01/A03　**预估**: 1 min
**前置条件**: 临时缓存目录。
**测试步骤**: 1. 对含 `../../etc/passwd`、`/`、`\0`、`..` 的文本调用 `SpeechEngine.key()` 与 `audio_path()`；2. 解析生成路径；3. 用 `parse()` 读取一个带 `../` 的路径与一个超长路径。
**预期结果**: ✅ key 为 24 位十六进制字符串；✅ `audio_path().parent == CACHE_DIR`，路径不含 `..`；✅ `parse` 对越界/超长路径返回 `failed` 而非抛异常或写出文件。
**通过/失败**: 缓存文件写到 CACHE_DIR 之外判 P0 失败。
**潜在缺陷**: 用原文当文件名导致任意路径写入。

### TC-SEC-003: 动态库注入面 — 清理 DYLD / PYTHON 环境变量
**优先级**: P1　**类型**: 安全 / A05　**预估**: 1 min
**前置条件**: 同 TC-CORE-013，但额外检查 `_run` 真实传给子进程的环境。
**测试步骤**: 1. 注入 5 个危险环境变量；2. 桩捕获 `subprocess.run` 的 `env` 参数；3. 检查 `cleaned_env()` 与全局环境。
**预期结果**: ✅ 子进程 env 中 `DYLD_*` / `LD_LIBRARY_PATH` / `PYTHONHOME` / `PYTHONPATH` / `_MEIPASS2` / `_PYI_ARCHIVE_FILE` 全部缺失；✅ 全局 `os.environ` 未被篡改；✅ `PATH` 系统目录优先。
**通过/失败**: 任一变量泄漏到子进程为失败。
**潜在缺陷**: PyInstaller 冻结应用加载冲突的 dylib（历史实测风险）。

### TC-SEC-004: 畸形与超大输入不崩溃
**优先级**: P1　**类型**: 安全 / A04　**预估**: 2 min
**前置条件**: 临时目录。
**测试步骤**: 1. 构造 1 MB 纯文本、10 万个标点、随机二进制字节（伪装 .txt/.pdf）；2. 分别调用 `parse`；3. 检查返回类型与耗时。
**预期结果**: ✅ 全部返回 `Document`，不抛未捕获异常；✅ 单文件解析 < 10 s；✅ 二进制文件不会产出含替换字符的巨量句子。
**通过/失败**: 崩溃、挂起或内存异常为失败。
**潜在缺陷**: 正则回溯、超大 PDF 无限制读取。

### TC-SEC-005: 错误信息不泄漏堆栈与绝对路径
**优先级**: P1　**类型**: 安全 / A05/A09　**预估**: 1 min
**前置条件**: 不存在的文件与损坏的 docx。
**测试步骤**: 1. `parse` 失败后检查 `error` 字段；2. 检查 controller 的 `message` 信号文本。
**预期结果**: ✅ `error` 为简短可读原因，不含 `Traceback`、不含堆栈帧；✅ 面向用户的提示使用文件名而非完整绝对路径；✅ 但错误足以让用户定位（含文件名或原因）。
**通过/失败**: 泄漏堆栈/内部路径为失败。
**潜在缺陷**: 直接把 `repr(exc)` 展示给用户。

### TC-SEC-006: 本地状态完整性与无密钥落盘
**优先级**: P1　**类型**: 安全 / A02/A08　**预估**: 2 min
**前置条件**: 临时 state.json，源码树可读。
**测试步骤**: 1. 保存状态并读取 JSON；2. 扫描键值中是否出现 `password/token/secret/api_key`；3. 静态扫描 `src/` 是否含硬编码密钥或网络凭证；4. 验证保存使用 `os.replace` 原子替换；5. 损坏文件后重载。
**预期结果**: ✅ JSON 仅含播放列表/设置/断点；✅ 无凭证字段；✅ 源码无硬编码密钥常量；✅ 原子替换且损坏可回退。
**通过/失败**: 任何凭证落盘或非原子写入为失败。
**潜在缺陷**: 未来接入在线 TTS 时密钥被写进 state.json。

### TC-SEC-007: 依赖版本约束与离线依赖面
**优先级**: P2　**类型**: 安全 / A06　**预估**: 1 min
**前置条件**: `requirements.txt` / `requirements-dev.txt` 可读。
**测试步骤**: 1. 检查每个依赖都有版本约束；2. 检查 `pymupdf<2`（避开附带 ONNX 布局模型的重型版本）；3. 静态扫描 `src/` 是否引入 `requests` / `urllib.request` / `socket` / `http.client`；4. 检查无 `os.system` / `shell=True` / `eval` / `pickle.loads`。
**预期结果**: ✅ 全部依赖有约束；✅ 无网络出站代码；✅ 无危险动态执行调用；✅ 语音完全由系统 `say` 离线合成。
**通过/失败**: 出现网络出站或动态执行为失败。
**潜在缺陷**: 文档内容被上传到第三方 TTS（用户明确禁止）。

### TC-SEC-008: 默认配置安全
**优先级**: P2　**类型**: 安全 / A05　**预估**: 1 min
**前置条件**: `DEFAULT_SETTINGS` 可读。
**测试步骤**: 1. 逐项检查默认设置；2. 检查缓存上限、音量、语速范围。
**预期结果**: ✅ `rate=200`、`volume=80`、`mode=sequence`、`auto_resume=True` 均为安全默认；✅ `cache_limit_mb=500` 存在；✅ 无「默认开启网络 / 默认管理员」类开关；✅ `MODES` 仅含四种已知模式。
**通过/失败**: 默认值越界或含未知模式为失败。
**潜在缺陷**: 缓存无上限撑爆磁盘。

### TC-SEC-009: 数值边界钳制（资源耗尽防护）
**优先级**: P2　**类型**: 安全 / A04　**预估**: 1 min
**前置条件**: 构造 `SpeechEngine` 与 `ReaderController`。
**测试步骤**: 1. `SpeechEngine(voice, -1)` 与 `rate=99999`；2. `controller.set_rate(9999)` / `set_volume(-100)`；3. `Timeline(doc, 0)`。
**预期结果**: ✅ 语速钳制到 [60,400]（controller 为 [80,350]）；✅ 音量钳制到 [0,1]；✅ `sec_per_char` 下限 0.05 生效；✅ 无除零。
**通过/失败**: 越界值被写入配置或崩溃为失败。
**潜在缺陷**: 负语速导致 `say` 挂起。

### TC-SEC-010: N/A 论证 — 无访问控制面
**优先级**: P2　**类型**: 安全论证 / A01　**预估**: 1 min
**前置条件**: 源码树可读。
**测试步骤**: 1. 静态扫描 `src/` 中 `rls` / `permission` / `role` / `admin` / `chmod` / `sudo` 相关调用；2. 确认所有文件访问均基于用户主动选择的本地路径。
**预期结果**: ✅ 无权限提升、无角色判断、无系统级越权写；✅ 结论「A01 不适用」成立，记录为已覆盖。
**通过/失败**: 出现越权文件系统操作则 N/A 结论不成立，须转为真实用例。
**潜在缺陷**: 未来加入云同步后此结论失效。

### TC-SEC-011: N/A 论证 — 无认证会话
**优先级**: P2　**类型**: 安全论证 / A07　**预估**: 1 min
**前置条件**: 源码树可读。
**测试步骤**: 1. 扫描 `login` / `session` / `cookie` / `csrf` / `jwt` / `oauth` 关键字；2. 确认无用户体系。
**预期结果**: ✅ 无认证相关代码；✅ 结论「A07 不适用」成立。
**通过/失败**: 出现会话管理代码则须补充真实认证测试。
**潜在缺陷**: 未来加入账号登录后此结论失效。

### TC-SEC-012: N/A 论证 — 无 SSRF 出站面
**优先级**: P2　**类型**: 安全论证 / A10　**预估**: 1 min
**前置条件**: 源码树可读。
**测试步骤**: 1. 扫描 `src/` 中的 URL 构造与网络客户端调用；2. 检查 `subprocess` 调用目标是否恒为 `/usr/bin/say` 与 `/usr/bin/afinfo` 绝对路径。
**预期结果**: ✅ 无 HTTP 客户端、无 URL 请求；✅ 子进程二进制路径为系统绝对路径，不接受用户输入；✅ 结论「A10 不适用」成立。
**通过/失败**: 出现用户可控 URL 请求则判 P0 失败。
**潜在缺陷**: 未来接入在线语音时须重做 SSRF 测试。
