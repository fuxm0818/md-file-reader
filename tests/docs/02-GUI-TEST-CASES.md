# 02 · GUI 与播放链路测试用例（权威来源）

**项目**：文档朗读器 v1.0.0　**分类**：GUI / 播放控制 / 播放列表 / 断点
**执行环境**：`QT_QPA_PLATFORM=offscreen`，音量置 0，隔离 `state.json` 与音频缓存目录。

---

### TC-GUI-001: 打开文档并开始朗读
**优先级**: P0　**类型**: E2E　**预估**: 3 min
**前置条件**: 隔离 Store 内加入 4 个样例文档；`QApplication` 已创建。
**测试步骤**: 1. 实例化 `ReaderController`；2. `select_item(0, auto_play=True)`；3. 读取 `doc / timeline / sentence_index / playing`。
**预期结果**: ✅ `doc.ok=True` 且句子数 > 0；✅ `timeline.total() > 0`；✅ `playing=True`；✅ `documentLoaded` 与 `stateChanged` 信号触发。
**通过/失败**: 文档未加载或播放器未进入播放态为 P0 失败。
**潜在缺陷**: 无中文音色时 `engine=None` 导致静默失败。

### TC-GUI-002: 暂停与继续不跳句
**优先级**: P0　**类型**: E2E　**预估**: 2 min
**前置条件**: 正在播放第 N 句。
**测试步骤**: 1. 记录当前 `sentence_index` 与 `player.position()`；2. `play_pause()` 暂停；3. 等待 300 ms；4. 再次 `play_pause()` 继续；5. 复查。
**预期结果**: ✅ 暂停后 `playing=False`、`playbackState=PausedState`；✅ 继续后 `playing=True`；✅ 两次的 `sentence_index` 相同，位置不回零。
**通过/失败**: 跳句或位置归零为失败。
**潜在缺陷**: 暂停被误判为 EndOfMedia 触发自动下一句。

### TC-GUI-003: 拖动进度吸附到句子边界
**优先级**: P0　**类型**: E2E　**预估**: 2 min
**前置条件**: 已加载多句文档。
**测试步骤**: 1. `seek_fraction(0.55)`；2. 读取新 `sentence_index`；3. 与 `timeline.sentence_at(0.55*total)` 比对；4. 再测 0.0 与 1.0 两个边界。
**预期结果**: ✅ 跳转后句子索引等于时间轴反查结果；✅ 边界不越界（0 ≤ index < 句数）；✅ `message` 含「跳到第 N 句」。
**通过/失败**: 落点不在句子起点或越界为失败。
**潜在缺陷**: 校准后时间轴失效导致吸附到错误句。

### TC-GUI-004: 点击正文任意句「从这里开始朗读」
**优先级**: P1　**类型**: E2E　**预估**: 1 min
**前置条件**: 已加载文档。
**测试步骤**: 1. `seek_sentence(min(5, 句数-1))`；2. 读取状态。
**预期结果**: ✅ `sentence_index` 等于目标句；✅ `playing=True`；✅ 消息含「从第 N 句开始朗读」。
**通过/失败**: 索引未变化或未播放为失败。
**潜在缺陷**: 高亮与朗读句不同步。

### TC-GUI-005: ±15 秒快进快退
**优先级**: P1　**类型**: E2E　**预估**: 1 min
**前置条件**: 已加载文档且时间轴 > 30 秒。
**测试步骤**: 1. 记录当前句；2. `skip_seconds(15)`；3. `skip_seconds(-15)`；4. 检查索引。
**预期结果**: ✅ 快进后索引 ≥ 原索引；✅ 回退后索引合法且不越界；✅ 全程不抛异常。
**通过/失败**: 出现负索引或 IndexError 为失败。
**潜在缺陷**: 句内 seek 与跨句切换的分支处理。

### TC-GUI-006: 上一句 / 下一句导航
**优先级**: P1　**类型**: E2E　**预估**: 1 min
**前置条件**: 已加载文档，位于第 3 句。
**测试步骤**: 1. `next_sentence()`；2. `prev_sentence()`；3. 在首句再调用 `prev_sentence()`。
**预期结果**: ✅ 索引 +1 后 -1 回到原值；✅ 首句继续上一句被钳制在 0；✅ 不越界。
**通过/失败**: 索引越界为失败。
**潜在缺陷**: 末句下一句应停在末句。

### TC-GUI-007: 播完自动切下一项与顺序模式收尾
**优先级**: P0　**类型**: E2E　**预估**: 2 min
**前置条件**: 列表含 3 个有效文档，`mode=sequence`。
**测试步骤**: 1. `select_item(0)`；2. 直接触发 `_advance()` 模拟末句播完（先把 `sentence_index` 设为末句）；3. 检查当前项与状态；4. 在最后一项重复；5. `next_item()` 手动切项。
**预期结果**: ✅ 当前项 `status=done` 且自动进入第 2 项；✅ 最后一项播完后 `playing=False` 并提示「列表播放完毕」；✅ 手动切项不越界。
**通过/失败**: 连播中断或越界为失败。
**潜在缺陷**: `_advancing` 重入导致重复切项。

### TC-GUI-008: 四种播放模式
**优先级**: P1　**类型**: E2E　**预估**: 2 min
**前置条件**: 列表含 3 项。
**测试步骤**: 1. `set_mode` 依次设 sequence / loop_all / loop_one / shuffle；2. 分别在末项调用 `_next_item(auto=True)`；3. 单项循环时触发 `_advance`。
**预期结果**: ✅ `loop_all` 回到第 0 项；✅ `loop_one` 回到本文档第 0 句且不切项；✅ `shuffle` 不选当前项；✅ `sequence` 自动收尾停止；✅ 设置被持久化到 state.json。
**通过/失败**: 任一模式行为不符为失败。
**潜在缺陷**: 随机模式打乱当前播放项。

### TC-GUI-009: 退出重开恢复断点并回退一句
**优先级**: P0　**类型**: E2E　**预估**: 3 min
**前置条件**: 隔离 state.json，第一份文档已加入列表。
**测试步骤**: 1. `select_item(0, auto_play=False)`；2. `seek_sentence(6)`；3. `shutdown()` 保存；4. 用同一 state.json 新建 controller 并 `restore_session()`；5. 读取 `sentence_index`。
**预期结果**: ✅ 保存的 bookmark 为 6；✅ 恢复后索引为 5（回退一句）；✅ 恢复后 `playing=False`；✅ 恢复的是同一个文件。
**通过/失败**: 未回退、回到第 0 句或自动开始播放均为失败。
**潜在缺陷**: 恢复时立即播放打断用户；hash 变化未提示。

### TC-GUI-010: 扫描件跳过且不中断连播
**优先级**: P1　**类型**: E2E　**预估**: 2 min
**前置条件**: 列表 = [有效 md, 无文字层 PDF, 有效 txt]。
**测试步骤**: 1. `select_item(1, auto_play=False)`；2. 等待 120 ms 让单次定时器触发；3. 检查该 item 的 `status/error` 与当前项。
**预期结果**: ✅ 该项 `status=error` 且 `error` 含「无文字层」；✅ 触发 message 提示「跳过…」；✅ 自动切到下一项，不抛异常。
**通过/失败**: 连播卡死或异常为失败。
**潜在缺陷**: 定时器 Lambda 捕获失效项索引。

### TC-GUI-011: 设置项生效并持久化
**优先级**: P1　**类型**: E2E　**预估**: 2 min
**前置条件**: 已加载文档。
**测试步骤**: 1. `set_rate(220)`；2. `set_volume(35)`；3. `set_mode('loop_all')`；4. `set_auto_scroll(False)`；5. `set_skip_code(False)`；6. 重新 `Store()` 读回；7. 测 `set_rate(9999)` 与 `set_volume(-5)` 边界。
**预期结果**: ✅ 所有设置写入 state.json；✅ `engine.rate` 同步；✅ 语速钳制到 ≤350，音量钳制到 [0,1]；✅ `_fmt(125)` 返回 `02:05`。
**通过/失败**: 设置未持久化或越界为失败。
**潜在缺陷**: 换语速后时间轴与缓存 key 未同步。

### TC-GUI-012: 后台估算标记不可用文档与估算时长
**优先级**: P1　**类型**: 集成　**预估**: 2 min
**前置条件**: 列表含正常 md 与扫描 PDF，隔离 state.json。
**测试步骤**: 1. `estimate_durations()`；2. 等待线程池完成（≤5 s）；3. 读取各项 `est_seconds / status / error / est_hash`。
**预期结果**: ✅ 正常文档 `est_seconds > 0`；✅ 扫描件 `status=error`、`error` 含「无文字层」；✅ 每项写入 `est_hash`；✅ 再次估算不重复解析（签名命中）。
**通过/失败**: 线程异常或标记未落地为失败。
**潜在缺陷**: 后台线程抛异常导致 Qt 报错。

### TC-GUI-013: 主窗口三栏组件与信号装配
**优先级**: P2　**类型**: GUI 冒烟　**预估**: 2 min
**前置条件**: offscreen QApplication，隔离 state.json。
**测试步骤**: 1. 实例化 `MainWindow`；2. 检查播放列表、正文阅读区、控制条三类组件存在；3. 检查菜单动作数量；4. 调用 `_refresh_list()` 与一次 `add_items`。
**预期结果**: ✅ 关键组件对象非空；✅ 列表行数与 Store 项数一致；✅ 无未捕获异常；✅ 窗口标题含「文档朗读器」。
**通过/失败**: 构造失败或列表不同步为失败。
**潜在缺陷**: 导入路径与相对导入不一致（历史缺陷）。

### TC-GUI-014: 停止与关闭不残留后台线程
**优先级**: P2　**类型**: 稳定性　**预估**: 1 min
**前置条件**: 已加载并播放文档。
**测试步骤**: 1. `stop()`；2. `reset()`；3. `shutdown()`；4. 检查 `playing / doc / timer / pool.activeThreadCount()`。
**预期结果**: ✅ `playing=False`、`doc=None`、定时器停止；✅ 线程池在 1 s 内收敛；✅ 全程无 Python 异常。
**通过/失败**: 线程残留或异常为失败。
**潜在缺陷**: 退出时工作线程访问已销毁对象。

### TC-GUI-015: 文件夹扫描按自然序排列文件名
**优先级**: P1　**类型**: 功能　**预估**: 1 min
**前置条件**: 临时目录内含 `1.md`、`2.md`、`3.md`、`11.md`、`21.md`、`第1章.md`、`第2章.md`、`第10章.md`。
**测试步骤**: 1. 调用 `collect_paths([目录])`；2. 取返回路径的文件名序列。
**预期结果**: ✅ 顺序为 `1、2、3、11、21、第1章、第2章、第10章`；✅ 数字段整体比较，不按字符逐位比较；✅ `第10章` 排在 `第2章` 之后。
**通过/失败**: 出现 `1、11、2、21` 这类字符串序为失败。
**潜在缺陷**: `sorted()` 直接作用于路径字符串，10 以上的编号全部错位。

### TC-GUI-016: 左右分栏宽度可拖且重开恢复
**优先级**: P2　**类型**: GUI　**预估**: 1 min
**前置条件**: offscreen QApplication，隔离 state.json。
**测试步骤**: 1. 实例化 `MainWindow`，检查中央区域是含两个子控件的 `QSplitter`；2. 检查拖拽热区宽度与左栏上下限；3. 在设置中写入 `sidebar_width=430` 并保存；4. 重新构造窗口并显示后读取 `splitter.sizes()`。
**预期结果**: ✅ `splitter.widget(0)` 是播放列表；✅ `handleWidth ≥ 4`；✅ 左栏最小 200、最大 620；✅ 重开后左栏宽度为 430。
**通过/失败**: 拖拽热区为 0、宽度未持久化为失败。
**潜在缺陷**: 固定宽度改分栏后忘记落盘，用户每次都要重新拖。

### TC-GUI-017: 窄窗口收起语速与音量
**优先级**: P2　**类型**: GUI　**预估**: 1 min
**前置条件**: 可构造 `ControlBar`。
**测试步骤**: 1. 以宽于 `COMPACT_LEAVE` 的宽度触发 `resizeEvent`；2. 读取语速下拉的隐藏状态；3. 以窄于 `COMPACT_ENTER` 的宽度再次触发；4. 读取语速、音量与进度条的隐藏状态。
**预期结果**: ✅ 宽窗口下语速可见；✅ 窄窗口下语速与音量收起；✅ 进度条始终可见。
**通过/失败**: 窄窗口仍显示语速音量为失败。
**潜在缺陷**: 这两个控件把控制栏最小宽度顶到 715 px，左栏因此最多只能拉到 395 px。

### TC-GUI-018: 系统深浅色切换时界面实时跟随
**优先级**: P1　**类型**: GUI　**预估**: 2 min
**前置条件**: offscreen QApplication，可替换 `theme.is_dark`。
**测试步骤**: 1. 构造 `MainWindow` 并调用 `theme.apply(app)`；2. 令 `theme.is_dark` 恒为 True 后调用 `theme.refresh(app)`；3. 检查主窗口、播放列表、控制栏、设置面板、复选框的 palette 与样式表；4. 恢复浅色后再次刷新。
**预期结果**: ✅ 各部件 `p.dark` 与当前外观一致；✅ 主窗口样式表包含对应主题的窗底色；✅ 图标与句级高亮按新配色重画，切回浅色后完全还原；✅ 切换过程不抛异常、不滚动正文。
**通过/失败**: 需要重启才变色，或切换后部分部件仍是旧配色，为失败。
**潜在缺陷**: palette 只在启动时算一次，深色模式下正文高亮与背景撞色。
