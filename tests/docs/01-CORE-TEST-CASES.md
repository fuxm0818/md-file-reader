# 01 · 核心层测试用例（权威来源）

**项目**：文档朗读器 v1.0.0　**分类**：CORE（解析 / 语音 / 时间轴 / 持久化）
**执行方式**：`QT_QPA_PLATFORM=offscreen .venv/bin/python tests/run_qa.py`
**原则**：本文档是用例规格的唯一真实来源；`TEST-EXECUTION-TRACKING.csv` 只记录执行状态，不得当作用例定义。

---

### TC-CORE-001: Markdown 解析为段落→句子模型并跳过代码块
**优先级**: P0　**类型**: 单元/集成　**预估**: 2 min
**前置条件**: `samples/示例文档.md` 存在，含标题、正文与围栏代码块。
**测试步骤**: 1. 调用 `parse(path, skip_code=True)`；2. 记录 `ok / sentences / headings / display_text`；3. 逐句校验 `display_text[start:end]`。
**预期结果**: ✅ `ok=True`；句子数 > 5 且含标题块；✅ 所有 `0 <= start < end <= len(display_text)`；✅ 代码关键字（如 `def` / `print`）不出现在任何句子的 `text` 中。
**通过/失败**: 三条断言全过为通过；任一 span 越界或代码块被朗读为失败。
**潜在缺陷**: 围栏未闭合时正文丢失；清洗后 span 与展示文本错位。

### TC-CORE-002: 纯文本解析与多编码回退
**优先级**: P0　**类型**: 单元　**预估**: 1 min
**前置条件**: 构造 utf-8 / utf-8-sig / gb18030 三种编码的 txt 临时文件。
**测试步骤**: 1. 对三种编码分别调用 `parse`；2. 比较句子文本。
**预期结果**: ✅ 三者 `ok=True` 且正文中文不乱码；✅ utf-8-sig 不出现 BOM 字符；✅ gb18030 与 utf-8 解析出的句子集合一致。
**通过/失败**: 任一编码解析失败或出现替换字符即失败。
**潜在缺陷**: `_decode` 顺序误判导致中文乱码。

### TC-CORE-008: 句子切分与长句按软标点拆分

### TC-CORE-010: 语速标定换算公式
**优先级**: P1　**类型**: 单元（模拟）　**预估**: 1 min
**前置条件**: `SpeechEngine` 使用临时缓存目录；`synthesize` 被桩替换返回固定 20 秒。
**测试步骤**: 1. 调用 `calibrate()`；2. 用 `CALIBRATION_TEXT` 去空白字符数复算。
**预期结果**: ✅ 返回值 ≈ `20 / 有效字数`，误差 < 1e-3；✅ 合成失败时回退 `DEFAULT_SEC_PER_CHAR=0.196`。
**通过/失败**: 换算不一致或未回退为失败。
**潜在缺陷**: 标点计入字数导致估算偏差。

### TC-CORE-011: 逐句真实语音合成与缓存命中
**优先级**: P0　**类型**: 集成（真实系统语音）　**预估**: 3 min
**前置条件**: `/usr/bin/say` 与 `/usr/bin/afinfo` 可用，至少一个系统音色。
**测试步骤**: 1. 选一个可用音色（中文优先）；2. `synthesize(text)`；3. 记录返回路径/时长；4. 用相同文本再调用一次并比对路径；5. 修改语速后再调用。
**预期结果**: ✅ 返回 `.aiff` 文件存在且大小 > 100 字节；✅ `duration > 0`；✅ 二次调用命中同一缓存路径；✅ 不同语速生成不同缓存 key。

### TC-CORE-015: 双坐标时间轴的估算→真实校准→反查
**优先级**: P0　**类型**: 单元　**预估**: 1 min
**前置条件**: 构造含 5 句的 Document，`sec_per_char=0.2`。
**测试步骤**: 1. 记录初始 `total()` 与 `start_of(3)`；2. `set_real(1, 9.0)`；3. 复查 total 与 starts；4. `sentence_at(t)` 反查；5. 测 `time_at_fraction(0.5)`。
**预期结果**: ✅ 真实时长替换估算值且 total 相应变化；✅ starts 单调；✅ `sentence_at(start_of(i)) == i`；✅ fraction 与 time 互逆（误差 < 1e-6）。
**通过/失败**: 校准后起点未重算或反查越界为失败。
**潜在缺陷**: 缓存未失效导致进度条跳变。

### TC-CORE-018: 断点写入、读取与文档变更失效
