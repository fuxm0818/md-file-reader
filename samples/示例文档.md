# 文档朗读器使用说明

这是一份用于测试朗读效果的样例文档。程序会把整篇文档按句子切开，再逐句合成语音。

## 一、边看边听

朗读时，当前正在读的句子会在正文中高亮，并自动滚动到视野内。你可以双击任意一句，或者右键选择「从这里开始朗读」，程序会立刻跳到那一句。

Markdown 的标题、列表和链接地址不会念出来。下面这段代码块也默认跳过，你可以一边听一边对照源码。

```python
def estimate(seconds_per_char, chars):
    return chars * seconds_per_char
```

## 二、进度条

文档本身没有时间轴，所以程序按语速把字数换算成时间。已经合成过的句子会用音频的真实时长替换估算值，剩余时间会越听越准。

拖动进度条时，落点会吸附到最近的句子边界，而不是停在一个无法朗读的任意秒数上。此外还有后退十五秒、前进十五秒、上一句和下一句四个快捷操作。

## 三、播放列表

可以像视频播放器那样，事先把几份文档拖进来排好顺序，然后一集一集连续播放。支持拖拽调整顺序，右键可以把某份文档插到「下一项播放」。

每个文档各自记住听到第几句。下次打开时会回退一句，方便重新接上上下文。扫描版 PDF 因为没有文字层，会被标记并跳过，不会打断连播。

- 支持 txt、Markdown、PDF、Word 文档
- 语音由 macOS 系统离线合成，不联网
- 音色、语速、音量都可以在偏好设置里调整
